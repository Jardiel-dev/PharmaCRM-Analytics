
# PharmaCRM Analytics

Projeto de portfólio para aprender SQL e desenvolver segmentações de clientes aplicadas a CRM.

## Objetivo

Construir uma solução demonstrativa para uma rede de farmácias fictícia, utilizando dados sintéticos de clientes, compras e produtos para apoiar a criação de públicos para campanhas de marketing.

## Tecnologias

- PostgreSQL
- SQL
- Git e GitHub
- Salesforce Marketing Cloud Engagement (conceitos e adaptação das consultas)

## Funcionalidades planejadas

- Consultar clientes e compras.
- Identificar clientes ativos e inativos.
- Calcular frequência e valor de compras.
- Criar e validar segmentos de clientes.
- Simular resultados de campanhas.
- Documentar como as segmentações podem ser utilizadas em CRM.

## Dados

O projeto utilizará exclusivamente dados fictícios. Não possui acesso a dados ou sistemas internos de empresas reais.
