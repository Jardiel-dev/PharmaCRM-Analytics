# PharmaCRM Analytics

Projeto de portfólio para aprender SQL e desenvolver segmentações de clientes aplicadas a CRM, simulando uma rede de farmácias fictícia.

---

## 🎯 Objetivo
Construir uma solução demonstrativa utilizando dados sintéticos de clientes, compras e produtos, aplicando conceitos de banco de dados relacionais e SQL para apoiar a criação de públicos para campanhas de marketing e CRM.

---

## 🛠️ Tecnologias Utilizadas
- **PostgreSQL** (Banco de dados relacional local)
- **SQL** (Linguagem de consulta e manipulação de dados)
- **Git e GitHub** (Controle de versão e portfólio)
- **Salesforce Marketing Cloud Engagement** (Estudo conceitual e adaptação de consultas)

---

## 📂 Estrutura do Projeto
- `sql/` — Contém os scripts DDL de criação de tabelas, scripts de carga de dados (*seed*) e consultas de segmentação.
- `docs/` — Documentação do modelo de dados e critérios de negócio.
- `data/` — Dados sintéticos e arquivos auxiliares.

---

## 🔒 Aviso sobre os Dados
Este projeto é independente e utiliza exclusivamente **dados fictícios**. Não possui qualquer vínculo ou acesso aos sistemas internos de empresas reais.
